## 📖 About Plateful

Plateful brings **food discovery and ordering** together in one place. Instead of relying only on traditional food listings, users can explore a **vertical video feed**, discover dishes from food partners, view prices, **save favourites**, manage their cart, and proceed to checkout.

Food partners get their own **dedicated dashboard** to upload food videos, manage food listings, and showcase their offerings.

The project combines an **interactive frontend** with **REST APIs**, **authentication**, **database integration**, and **cloud deployment**.

## ✨ Features

### 👤 For Users

- 🔐 **Secure User Authentication** — Registration and login.
- 🎥 **Video-First Food Discovery** — Explore food through interactive video reels.
- 🍜 **Discover Food Partners** — Find dishes shared by food partners.
- 🔖 **Save Favourites** — Keep favourite food items for later.
- 🛒 **Smart Cart Management** — Add items and manage quantities.
- 💳 **Checkout Flow** — Review cart items and proceed through checkout.
- 👤 **User Profile** — View and manage profile information.

### 🏪 For Food Partners

- 🔐 **Dedicated Authentication** — Separate food-partner login.
- 📊 **Partner Dashboard** — View available food and engagement statistics.
- 🎬 **Food Video Uploads** — Showcase dishes through video reels.
- ✏️ **Food Listing Management** — Add and edit food details.
- 🗑️ **Delete Listings** — Remove food items when needed.
- 🖼️ **Business Profile Management** — Manage profile information and profile photo.

### ⚙️ Technical Highlights

- **RESTful API Integration** between frontend and backend.
- **MongoDB Atlas** database integration using **Mongoose**.
- **Cookie-Based Authentication** and protected API endpoints.
- **Video Uploads** and food-media handling.
- **Separate Frontend and Backend Deployments** on Render.

## 💻 Run Locally

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd Zomata-Mern-project
```

### 2. Install and Start the Backend

```bash
cd Backend
npm install
npm start
```

Configure the backend `.env` file with your **MongoDB connection string** and other required environment variables.

### 3. Start the Frontend

Open a separate terminal:

```bash
cd Frontend
npm install
npm run dev
```

Create `Frontend/.env` with:

```env
VITE_API_URL=http://localhost:3000
```

The backend typically runs at `http://localhost:3000`, while the frontend runs at `http://localhost:5173`.
