## 📖 About Plateful

Plateful brings **<u>food discovery and ordering</u>** together in one place. Instead of relying only on traditional food listings, users can explore a **<u>vertical video feed</u>**, discover dishes from food partners, view prices, **<u>save favourites</u>**, manage their cart, and proceed to checkout.

Food partners get a **<u>dedicated dashboard</u>** to upload food videos, manage food listings, and showcase their offerings.

The project combines an **<u>interactive frontend</u>** with **<u>REST APIs</u>**, **<u>authentication</u>**, **<u>database integration</u>**, and **<u>cloud deployment</u>**.

## ✨ Features

### 👤 For Users

- 🔐 **<u>User Authentication</u>** — Register and log in.
- 🎥 **<u>Video-First Food Discovery</u>** — Explore food through interactive video reels.
- 🍜 **<u>Discover Food Partners</u>** — Find dishes shared by food partners.
- 🔖 **<u>Save Favourites</u>** — Keep favourite food items for later.
- 🛒 **<u>Smart Cart Management</u>** — Add items and manage quantities.
- 💳 **<u>Checkout Flow</u>** — Review cart items and proceed through checkout.
- 👤 **<u>User Profile</u>** — View and manage profile information.

### 🏪 For Food Partners

- 🔐 **<u>Dedicated Authentication</u>** — Separate food-partner login.
- 📊 **<u>Partner Dashboard</u>** — View available food and engagement statistics.
- 🎬 **<u>Food Video Uploads</u>** — Showcase dishes through video reels.
- ✏️ **<u>Food Listing Management</u>** — Add and edit food details.
- 🗑️ **<u>Delete Listings</u>** — Remove food items when needed.
- 🖼️ **<u>Business Profile Management</u>** — Manage profile information and profile photo.

### ⚙️ Technical Highlights

- **<u>REST API Integration</u>** — Connect frontend and backend services.
- **<u>MongoDB Integration</u>** — Store application data using Mongoose.
- **<u>Cookie-Based Authentication</u>** — Manage login sessions through cookies.
- **<u>Protected API Endpoints</u>** — Restrict access to authenticated features.
- **<u>Video and Media Handling</u>** — Support food video uploads.
- **<u>Full-Stack Deployment</u>** — Deploy frontend and backend separately on Render.

## 💻 Run Locally

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd Zomata-Mern-project
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your actual GitHub repository URL.

### 2. Install and Start the Backend

```bash
cd Backend
npm install
npm start
```

Configure the backend `.env` file with your **<u>MongoDB connection string</u>** and other required environment variables.

### 3. Start the Frontend

Open a separate terminal:

```bash
cd Frontend
npm install
npm run dev
```

Create `Frontend/.env` with:

```env
VITE_API_URL=http://localhost:3000
```

The backend typically runs at `http://localhost:3000`, while the frontend runs at `http://localhost:5173`.
