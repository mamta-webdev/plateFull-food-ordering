📖 About Plateful

Instead of browsing through traditional food listings, users can explore a vertical, video-based food feed, discover dishes shared by food partners, view prices, save favourites, and add items to their cart.

Plateful also provides food partners with their own dashboard to manage their food listings, upload food videos, and showcase their offerings.

The project focuses on combining an engaging frontend experience with real backend functionality, authentication, database integration, and deployment.

✨ Features
👤 For Users
- 🔐 User registration and login
- 🎥 Explore food through video reels
- 🍜 Discover dishes shared by food partners
- 🔖 Save favourite food items
- 🛒 Add items to the cart and manage quantities
- 💳 Checkout flow for placing orders
- 👤 View and manage user profile
🏪 For Food Partners
- 🔐 Dedicated food partner authentication
- 📊 Dashboard with food and engagement statistics
- 🎬 Upload food videos and create food reels
- ✏️ Edit food details and manage posted items
- 🗑️ Delete food items
- 🖼️ Manage business profile information and profile photo
⚙️ Technical Highlights
- REST API integration between frontend and backend
- MongoDB database integration using Mongoose
- Cookie-based authentication
- Protected API endpoints
- Video upload and food media handling
- Separate frontend and backend deployments on Render
