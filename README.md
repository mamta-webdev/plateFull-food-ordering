## 📖 About Plateful

Plateful brings food discovery and ordering together in one place. Users can explore a vertical video feed, discover dishes from food partners, view prices, save favourites, manage their cart, and proceed to checkout.

Food partners get their own dashboard to upload food videos, manage food listings, and showcase their offerings.

The project combines an interactive frontend with backend APIs, authentication, database integration, and deployment.

## ✨ Features

### 👤 For Users
- 🔐 User registration and login
- 🎥 Explore food through video reels
- 🍜 Discover dishes shared by food partners
- 🔖 Save favourite food items
- 🛒 Add items to the cart and manage quantities
- 💳 Checkout flow
- 👤 View and manage user profile

### 🏪 For Food Partners
- 🔐 Dedicated food-partner authentication
- 📊 Dashboard with food and engagement statistics
- 🎬 Upload food videos and create food reels
- ✏️ Edit food details and manage listings
- 🗑️ Delete food items
- 🖼️ Manage business profile information and profile photo

### ⚙️ Technical Highlights
- REST API integration between frontend and backend
- MongoDB integration using Mongoose
- Cookie-based authentication and protected API endpoints
- Video uploads and food-media handling
- Separate frontend and backend deployments on Render

## 💻 Run Locally

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd Zomata-Mern-project
```

**2. Install and start the backend**

```bash
cd Backend
npm install
npm start
```

Configure the backend `.env` file with your MongoDB connection string and other required environment variables.

**3. Start the frontend**

Open a separate terminal:

```bash
cd Frontend
npm install
npm run dev
```

Create `Frontend/.env` with:

```env
VITE_API_URL=http://localhost:3000
```

The backend typically runs at `http://localhost:3000`, and the frontend at `http://localhost:5173`.
